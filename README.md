# GregTech-Foundation
A GTCEu modpack designed as an introduction to GregTech for beginners.
# Title
**GregTech: Foundation**
Abbreviated as **GTF**.
# 1. Overview
`Nomifactory CEu` and `GTCEu Community Pack` can be quite challenging...
“What if there were a more beginner-friendly GregTech modpack that is easier to progress through?”
GTB was created from this idea: a modpack that is easier to progress through without sacrificing the fun of GregTech.
GTB uses **GTCEu**.
## Target Players
GTB is intended for:
* Players who want to try GregTech but do not want an extremely long progression
* Players who have experience with other tech mods and want to try GregTech
Of course, everyone is welcome!
# 2. Features
## Theme: "GregTech Without Giving Up"
Elements that can be difficult for beginners, such as long processing times and large numbers of intermediate materials, have been reduced as much as possible.
The goal is to make GregTech easier to progress through while keeping it enjoyable.
## Main Changes
* Earlier access to AE2 and easier recipes
* 2x or 4x output for some recipes
* Infinite ores and liquid resources
* Custom machines that speed up time-consuming recipes
* A Superflat world for building large-scale factories
* And more
# 3. Supported Environment
* Minecraft 1.20.1
* Forge
* GTCEu Modern
* 6–8 GB of RAM recommended
# 4. How to Launch
**This information may be incomplete. We recommend searching for additional information if necessary.**
1. Download the latest ZIP file from `Releases`.
2. Import it into `Prism Launcher` or `CurseForge Launcher`.
3. Launch the modpack as usual.
